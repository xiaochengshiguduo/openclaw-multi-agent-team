# 任务生命周期

标准生命周期：

```text
intake → clarify → plan → execute → review → final → archived
```

## 阶段

- `intake`：用户提出工作请求。
- `clarify`：`main` 或 PM 解决阻塞性歧义。
- `plan`：创建任务归档与路由计划。
- `execute`：选定的角色 Agent 参与贡献。
- `review`：按需进行 QA/reviewer/security/devops 检查。
- `final`：`main` 汇总形成最终交付。
- `archived`：不再有活跃工作。

终止状态：

```text
blocked | cancelled
```
