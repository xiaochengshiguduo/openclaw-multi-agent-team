# Config Examples

Configuration examples are placeholders. They are not real OpenClaw runtime config files.

See:

- `examples/config/agent-to-agent.example.json5`
- `examples/config/agents.example.json`
- `examples/config/openclaw-config-patch.example.json5`

## Safety

Before applying any config patch:

1. Back up your current OpenClaw config.
2. Review the patch.
3. Validate against your OpenClaw version/schema.
4. Apply explicitly.
5. Restart Gateway manually only if required.

This project does not include real tokens, auth profiles, Telegram bot tokens, model keys, or Gateway tokens.
